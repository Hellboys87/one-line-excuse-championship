# One-Line Excuse Championship

A tiny Node program that writes a single funny excuse from an AI agent to its human — the file it deleted, and the apology it deleted right after.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is unset), with no trailing newline.
